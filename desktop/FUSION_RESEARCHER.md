# SleepWell 연구자용 Windows 0.4.1

작성: 2026-10-24

## 제품 역할
- Android: 사용자 기록·수면의 질 확인·권장 일정 제공을 담당하는 사용자 앱.
- Windows: 모델 실행, 모델별 예측 비교, 사용 이후 관측 결과 검증을 담당하는 연구자 소프트웨어.
- 현재 물리모델은 고정 시간상수의 Two-Process 모델이다. PCR 모델은 아직 이 실행 경로에 포함되지 않는다.

## 이번에 탑재한 모델
2026-10-20 robust-next-night-research-v2 실험의 CMI 및 MESA 학습 모델을 그대로 포터블 JSON으로 변환한다. 각 집단의 물리 단독·데이터 단독·융합 모델이 같은 과거 이력으로 다음 주수면 입면과 최종 기상을 예측한다. 개인 Samsung 학습 모델과 참가자 원자료는 배포하지 않는다. 원래 fitted 모델과 포터블 추론의 수치 일치 검증은 별도 검증 기록에 남긴다.

수면 시간대 예측을 건강 개선 목표로 오해하지 않는다. 데이터 모델이 예측한 불규칙한 생활을 그대로 권장하지 않는다. 현재 권장 정책은 목표 기상·수면 기회·생활 위상·Two-Process에 따른 별도의 제약 계산이며, 융합 모델의 행동 예상과 함께 비교한다. 연구 자료에서 융합이 데이터 단독보다 우수하다는 결론은 없다.

## 사용 이후의 변화
가입 이후의 직접 입력 일지를 주 지표로 사용한다. 개운함과 피로도는 응답이 있는 날만 계산하고, 수면 시각 규칙성은 원형 표준편차로 표시한다. 기기 자동 측정은 착용과 감지 영향을 받으므로 보조 집계로 분리한다. 사용 전 아카이브는 사용 효과 집계에 넣지 않는다. 초기와 최근 기간의 변화는 기술 통계이며 대조군 없는 인과효과가 아니다.

수면압력 S는 센서에서 측정한 값이 아니라 모형 계산값이다. 각성 중 축적되고 수면 중 감소하는 흐름을 참고한다. 하루 종일 S를 낮추는 것을 최적화 목표로 삼지 않는다. 주관적 수면의 질을 웨어러블 단계로 대체하거나 합성 점수로 만들지 않는다.

## 예측 검증
20:00까지 알려진 완료 기록만 사용한다. 20:00~20:15 최초 저장 예측은 주 검증 창이고, 늦은 생성은 참고용이다. 기존 예측은 새 버전으로 다시 쓰지 않는다. 집단 모델의 파일 해시·특징 계약·계산 입력을 예측 스냅샷에 저장한다. 이전 3개 비교군과 새 6개 연구 모델을 버전별로 구분한다. 직접 입력과 자동 측정 결과도 분리한다.

앱 개인화 추천의 14일 반감기와 연구 모델 특징의 기존 개인화 계약은 서로 다르다. 연구 모델의 특징을 임의로 바꾸면 저장된 검증 성능을 유지할 수 없으므로, 원래 특징 계산을 보존한다. 상수나 물리모델을 PCR로 교체할 때에는 새로운 모델·특징 버전과 독립 평가가 필요하다.

## 실행과 저장
이전 Windows 앱을 종료한 뒤 새 ZIP을 전부 풀고 SleepWell.exe를 실행한다. 신규 PC는 설치파일을 쓸 수 있다. 기록은 기존과 같이 Windows 사용자별 LOCALAPPDATA/SleepWell에 저장된다. 업데이트는 과거 기록과 휴대폰 등록을 삭제하지 않는다. 같은 PC의 저장소는 한 참여자의 기록을 위한 구조이며 여러 참가자를 한 프로필에 합치지 않는다.

연구자용 배포에는 원자료·개인 모델·연결 비밀키·사용자 데이터베이스가 들어 있지 않다. 앱 시작만으로 데이터를 외부에 업로드하지 않는다. Android 연동은 기존처럼 사용자가 시작하는 개인 네트워크 전송이다.


## 0.3.1 연구 진단 화면

실행하면 연구 화면이 먼저 열립니다. PC에 참여자 프로필을 입력할 필요 없이
CMI/MESA의 물리·데이터·융합 모델 성능을 표와 그래프로 비교합니다.
휴대폰에서 받은 기록은 기기·참여자별로 따로 선택하며 원본 백업을 변경하지 않습니다.
수동 프로필·일지 입력은 선택적인 시뮬레이션입니다.

평가 MAE는 입면/최종 기상 시각 예측 오차이며 수면의 질 점수가 아닙니다.
기존 검증·테스트 자료를 재사용한 연구 결과이므로 새로운 외부 검증으로 해석하지 마세요.
휴대폰 결과는 표시된 검증 범위 안에서만 해석합니다. 실제 오차를 계산하려면
예측 전에 고정된 입력과 예측 후 실제 결과가 필요하며, 재계산 일치는 정확도 증명이 아닙니다.
고정된 생리 시간상수와 행동 기록에서 추정하는 개인화 값을 구분합니다.
추천용 최근성 개인화와 학습 당시 계약을 보존한 연구 예측의 개인화는 서로 다릅니다.

앱을 종료하고 새 배포판을 실행하세요. 기록은 기존 사용자별 저장소에 유지됩니다.
기존 설치 경로를 덮어쓰지 않는 설치기이므로 새 버전용 경로를 선택하거나
새 버전 ZIP 전체를 별도 폴더에 풀어 실행합니다.


## 0.4.1 매일 개인화

추천용 행동 상수는 첫 유효 기록부터 갱신하며, 최근성 반감기와 수축 강도는 유지합니다. 평일·주말 패턴은 각각 2개 이상 기록이 있을 때 탐색적으로 표시합니다. 연구 화면의 “매일 갱신 상수” 영역은 기존 방식과 새 방식의 별도 연구 비교입니다. 기존 고정 연구 모델을 교체한 결과가 아니며, 추가 잔차 비교 또한 성능 향상이나 생리 상수 측정을 의미하지 않습니다. 자세한 내용은 배포 docs/매일 개인화 갱신 안내.md를 참고하세요.
