# SleepWell 연구자용 Windows 사용 안내

버전 0.4.3 · Windows 10/11 64비트 · 연구자용 로컬 프로토타입

CMI·MESA 연구용 융합 모델의 실제 추론과 사용 후 습관 지표를 확인할 수 있습니다. `docs/연구자 융합모델 안내.md`를 먼저 확인하세요. PCR은 아직 탑재하지 않았습니다.

이번 버전에는 Android 14 이상 휴대폰의 Health Connect 수면 기록을 받는 기능이 추가되었습니다.
설정 방법과 연동 범위는 함께 제공한 `docs/휴대폰 연결 안내.md`를 확인하세요.
기존 수동 입력·개인화·예측 사전 저장 기능을 유지합니다.

## 다른 PC에 설치하기

`SleepWell-Setup-0.4.3-x64.exe`를 대상 PC로 옮겨 실행하고 **설치**를 누르세요. Python을 따로 설치하거나 명령을 입력할 필요가 없습니다. 설치 중 바탕 화면·시작 메뉴 바로가기 생성 여부를 고를 수 있습니다. 관리자 권한이나 인터넷 연결은 필요하지 않습니다.

설치본은 `%LOCALAPPDATA%\Programs\SleepWell`에 저장됩니다. 이 초기 설치기는 기존 설치를 자동으로 덮어쓰지 않습니다. 같은 버전이 이미 설치되어 있으면 기존 SleepWell을 실행하세요.

설치 없이 쓰려면 `SleepWell-0.4.3-win-x64.zip`을 **전체 압축 해제**한 뒤 `SleepWell.exe`를 실행하세요. 실행파일만 따로 옮기면 동작하지 않습니다. 두 방식은 같은 Windows 사용자에게 같은 기록 저장소를 사용합니다.

현재 실행파일은 디지털 서명되지 않았습니다. 조직 정책이나 Windows 보안에서 실행을 차단하는 PC에는 서명된 배포본이 필요할 수 있습니다. 보안 기능을 끄는 방식은 안내하지 않습니다.

## 실행과 종료

SleepWell 아이콘을 누르면 실행 제어창과 연구 분석 화면이 열립니다. Edge가 있으면 앱 형태의 창을 우선 사용하고, 사용할 수 없으면 기본 브라우저로 엽니다. 주소는 PC 내부의 임시 포트를 사용하므로 기존 웹앱 주소 `127.0.0.1:8765`와 다를 수 있습니다.

- **화면 열기**: 연구 분석 화면을 다시 엽니다.
- **기록 폴더 열기**: 이 PC의 기록 저장 위치를 엽니다.
- 제어창의 닫기 버튼: 알림 영역으로 숨기고 실행을 유지합니다.
- **종료**: SleepWell이 시작한 로컬 서버를 정상 종료합니다. 별도로 실행한 기존 연구 웹앱은 종료하지 않습니다.

20시 사전 예측을 자동 저장하려면 **PC가 깨어 있고 SleepWell이 실행 중**이어야 합니다. 창이 보이지 않아도 알림 영역에서 실행 중이면 저장됩니다. 절전·PC 종료 중에는 저장하지 않습니다. Windows 로그인 시 자동 시작은 설정하지 않았습니다.

## 수동 시뮬레이션 사용하기

1. 시작 정보에서 나이·생활 특성·평소 수면을 입력합니다.
2. 오늘의 리듬에서 다음날 근무·수업·첫 일정, 기상 후 준비·이동 시간, 오늘 완료한 낮잠과 섭취한 카페인을 저장합니다.
3. 당일 예측에 포함하려면 20시 전에 저장합니다. 일정이 없는 날에도 확인란을 체크하고 빈 목록으로 저장하면 ‘없음’으로 기록됩니다.
4. 다음날 실제 수면과 컨디션을 입력합니다. 기존 기록을 고칠 때는 **나의 변화 → 수정**을 사용합니다.
5. 첫 유효 기록부터 최근 기록에 더 큰 비중을 두며 매일 개인화합니다. 기록 공백이 길어지면 초기값의 비중이 높아집니다.

20:00~20:15에 처음 저장된 예측을 주 평가에 포함합니다. 늦게 실행한 날과 실제 수면 시작 뒤 생성된 예측은 주 평가에서 제외합니다. 과거 예측을 소급 생성하지 않으며, 최초 실제 결과와 수정 결과를 따로 집계합니다.

## 기록·백업

개인 기록: `%LOCALAPPDATA%\SleepWell\sleepwell.sqlite3`

배포 파일에는 사용자 기록, Samsung 개인 모델, MESA·CMI 연구 원자료가 들어 있지 않습니다. NHANES의 익명 집단 평균만 초기값으로 포함합니다. 각 Windows 사용자는 자기 기록으로 시작합니다. 기존 T9 연구 웹앱의 DB는 자동으로 옮기거나 변경하지 않습니다.

앱의 **전체 기록 내려받기**로 JSON을 저장할 수 있습니다. 동일 버전에서 기록을 다른 PC로 옮길 때는 양쪽 SleepWell을 완전히 종료한 뒤 `sleepwell.sqlite3`를 별도로 백업하여 옮기세요. 대상 PC에 이미 기록이 있으면 먼저 그 DB를 백업해야 합니다. 자동 병합·JSON 복원 기능은 없습니다. 개인 기록을 다른 사람에게 배포하는 설치파일에 넣지 마세요.

프로그램을 제거할 때는 SleepWell을 종료하고 설치 폴더와 바로가기를 제거하면 됩니다. `%LOCALAPPDATA%\SleepWell`의 기록은 별도로 보존됩니다. 이 초기 설치본은 Windows ‘설치된 앱’ 제거 항목과 자동 업데이트를 제공하지 않습니다.

## 기능 범위

수면 일정 추천, 일정·낮잠·카페인 입력, 최근 기록·공백을 반영한 개인화, 사전 예측 저장과 실제 결과 비교를 제공합니다. 카페인 효과 계수, 개인별 생리 시간상수 추정, 스마트워치 자동 연동, 수면 개선 효과는 검증 완료된 기능이 아닙니다.

초기값은 NHANES 2017–2018 집단의 관측 평균이며 최적 필요수면을 뜻하지 않습니다. 예측 대상은 입면·최종 기상 시각으로, PSG 총수면시간이나 치료 효과와 다릅니다. 현재 시간대는 한국(Asia/Seoul)입니다.

패키지에는 공식 CPython 3.14.7 내장형 런타임과 tzdata 2026.2가 포함됩니다. Python 경로와 설치된 다른 패키지의 영향을 받지 않도록 격리했습니다. 라이선스와 구성요소 목록은 `runtime/LICENSE.txt`, `licenses/`에 있습니다.

다른 PC에서의 실행을 위해 패키징했지만, 실제 검증은 현재 Windows PC에서 독립 런타임·새 데이터 폴더·새 설치 경로를 사용해 수행했습니다. 별도 물리 PC에서의 호환성 검증은 아직 수행하지 않았습니다.


## 0.3.1 연구 진단 화면

실행하면 연구 화면이 먼저 열립니다. PC에 참여자 프로필을 입력할 필요 없이
CMI/MESA의 물리·데이터·융합 모델 성능을 표와 그래프로 비교합니다.
휴대폰에서 받은 기록은 기기·참여자별로 따로 선택하며 원본 백업을 변경하지 않습니다.
수동 프로필·일지 입력은 선택적인 시뮬레이션입니다.

평가 MAE는 입면/최종 기상 시각 예측 오차이며 수면의 질 점수가 아닙니다.
기존 검증·테스트 자료를 재사용한 연구 결과이므로 새로운 외부 검증으로 해석하지 마세요.
휴대폰 결과는 표시된 검증 범위 안에서만 해석합니다. 실제 오차를 계산하려면
예측 전에 고정된 입력과 예측 후 실제 결과가 필요하며, 재계산 일치는 정확도 증명이 아닙니다.
고정된 생리 시간상수와 행동 기록에서 추정하는 개인화 값을 구분합니다.
추천용 최근성 개인화와 학습 당시 계약을 보존한 연구 예측의 개인화는 서로 다릅니다.

앱을 종료하고 새 배포판을 실행하세요. 기록은 기존 사용자별 저장소에 유지됩니다.
기존 설치 경로를 덮어쓰지 않는 설치기이므로 새 버전용 경로를 선택하거나
새 버전 ZIP 전체를 별도 폴더에 풀어 실행합니다.

## 0.4.1 예측·추천·효과 분리

연구 화면은 기존 물리·데이터·융합 모델과 추가 개인화 보정의 오차, 적용 가능한 밤의 수, 참가자 단위 신뢰구간을 보여줍니다. 보정 전 모델도 이미 개인 수면 이력을 사용합니다. 추가 보정은 성능 향상이 입증되지 않아 연구 비교로만 저장하며 추천의 기본 정책으로 승격하지 않았습니다.

휴대폰 참여자 분석에서는 최초 사전 예측, 최초 수면일지 결과, 추천의 실제 화면 노출 시각, 행동 매개변수와 고정 생리 상수를 구분합니다. 웨어러블은 보조 지표입니다. 기록 변화는 기술 통계이며 추천의 인과적 효과를 뜻하지 않습니다.

`docs/연구 보완 및 검증 결과.md`와 `docs/추가 데이터와 실험.md`에 결과 및 후속 검증 요건을 정리했습니다.


## 0.4.1 매일 개인화

추천용 행동 상수는 첫 유효 기록부터 갱신하며, 최근성 반감기와 수축 강도는 유지합니다. 평일·주말 패턴은 각각 2개 이상 기록이 있을 때 탐색적으로 표시합니다. 연구 화면의 “매일 갱신 상수” 영역은 기존 방식과 새 방식의 별도 연구 비교입니다. 기존 고정 연구 모델을 교체한 결과가 아니며, 추가 잔차 비교 또한 성능 향상이나 생리 상수 측정을 의미하지 않습니다. 자세한 내용은 배포 docs/매일 개인화 갱신 안내.md를 참고하세요.
