# SleepWell: 추가 데이터와 실험

작성일 2026-10-25. 목표는 (1) 실제 입면·기상 예측, (2) 실현 가능한 수면 일정 추천, (3) 독립적으로 측정한 규칙성과 주간 기능 개선이다. 아래 설계는 확정된 효능이나 개인별 최적 수면량을 의미하지 않는다.

## 보유 자료의 용도와 한계

| 자료 | 현재 사용할 수 있는 역할 | 이 자료만으로 검증할 수 없는 것 |
|---|---|---|
| CMI 수면 이벤트 | 참가자 분리 다음 주수면 시각 예측; 일부 14일 이후 개인화 비교 | 추천의 인과효과, PSG 기준 총수면시간/질 |
| MESA ACT 파생 구간 | 초기 사용자와 단기 이력의 행동 예측; 참가자별 오차 | 현재 캐시의 과거 이력 최대 12일이므로 14일 전환 이후 효과 |
| MESA PSG, SleepEDF, Walch | 동시 측정에 한정한 수면/각성 라벨 및 센서 오차 점검 | 다주간 추천 사용 효과; 서로 다른 과제를 하나의 정확도로 합치기 |
| Samsung 개인 과거 기록 | 시계열 공백·장치 오차·분포 변화의 보조 사례 | 다른 사람에 대한 일반화, SleepWell 사용 효과 |
| NHANES 설문 | 연령·성별·자기보고 활동 수준별 관측 분포/초기값 | 개인의 필요 수면량 또는 최적 처방량 |
| NHANES 활동·조도 | 단위·비착용 처리와 집단 분포 참고 | 손목 lux를 망막 광노출로 치환; 다른 조사 주기를 동일 사람처럼 결합 |
| MMASH | 단기 생리·활동 맥락의 탐색 | 장기 개인화와 권장 일정 효과 |
| 국내 조사 보고서, AI Hub 돌봄/치매 관련 자료 | 대상 인구·라벨·시간 단위·연속 관측기간을 확인한 뒤 보조 용도 평가 | 한국 청년/일반 성인에게 자동 일반화, 파일명만으로 학습 적합성 확정 |

기존 자료는 함부로 한 테이블로 합치지 않는다. onset/bedtime, final wake/out-of-bed, TST/수면 구간, 기기별 활동 단위를 먼저 일치시켜야 한다. 희귀 행동을 센서 오류로 단정해 제외하지 않는다.

## 우선 추가할 관측 항목

- 매일: 침상 진입, 잠들기까지 시간, 밤중 각성 총시간, 최종 각성, 침상 이탈. 원래 응답과 입력/수정 시각을 보존한다.
- 다음날 일정: 근무·수업 시작/종료, 첫 일정, 이동·준비시간. 예측 전에 확인된 버전만 입력한다.
- 낮잠: 시작/종료와 기록 시각. 카페인: 시각과 추정 mg; 결측은 0과 구분한다.
- 결과: 회복감과 일정 시각의 졸림; 측정도구·언어판·범위·시각을 기록한다. 현재 Windows 피로 0–10과 Android 피로 1–5는 직접 합치지 않는다.
- 품질: 수기/센서 출처, 기기/알고리즘 버전, 착용·동기화 공백, 시간대, 원본과 정정의 연결.
- 추천: 생성 시각, 화면에 표시된 시각, 당시 일정과 모델 버전, 추천 수락 여부(향후 수집), 실제 이행. 화면 표시는 읽음/이행 증거와 다르다.

Consensus Sleep Diary를 기준으로 설문 의미를 정리한다. 기존 사용자 문항을 바꾸는 경우 새 문항 버전을 부여하고 과거 점수를 소급 변환하지 않는다. [Carney 등, 2012](https://pubmed.ncbi.nlm.nih.gov/22294820/)

## 장기 개인화 검증: 먼저 수행할 전향 관찰 연구

예시 설계는 2주 초기 관찰 + 6주 추적이다. 이 기간은 실행 가능한 출발안이며 생리 상수 식별의 충분조건이 아니다. 대상은 먼저 하나의 명확한 인구집단으로 정한다(예: 일정이 있는 성인 대학생). 교대근무·수면장애 등은 무조건 삭제하지 말고 연구의 적용 범위와 별도 층으로 사전 정의한다.

1. 신규 참가자 전체를 기존 개발 자료와 분리한다. 동일 참가자의 밤을 임의로 학습/시험에 섞지 않는다.
2. 매일 정해진 시각에 모든 비교 모델의 출력을 함께 저장한다. 단말이 꺼져 미생성한 밤은 누락으로 남기고 소급해 채우지 않는다.
3. 평가 대상 밤보다 앞서 관측·입력된 결과만 개인화에 쓴다. 현재 밤 정답, 사후 변경된 일정, 미래 보간값은 금지한다.
4. 비교: 단순 최근 기준, 기존 데이터/융합, 각 모델에 같은 추가 개인별 잔차 보정. 전체 밤과 보정 활성 밤을 모두 보고한다.
5. 사전 정한 기간별·공백별 성능과 참가자 균등 MAE를 보고한다. 3/7/14/28일 이력 제한 비교를 한다면 같은 미래 밤에서 비교하여 참가자 이탈/달력 효과와 혼동하지 않는다.
6. 예측구간은 별도 보정 자료로 구축하고 실제 포함률·폭을 검증해야 한다. 모델 간 차이나 평균 MAE를 개인의 95% 예측구간이라고 표시하지 않는다.

현 실험은 이미 확인한 시험 자료의 재분석이다. 순차 처리로 미래 누수를 막았다고 해서 독립적 외부 확인 연구가 되는 것은 아니다. [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378), [PROBAST+AI](https://www.bmj.com/content/388/bmj-2024-082505)

## 추천 효과: 별도의 대조시험

- 기록만 하는 대조군과 개인화 추천군을 무작위 배정하는 평행군 설계를 우선 검토한다. 습관 변화의 잔류효과 때문에 단순 교차시험은 주의한다.
- 주 평가변수 하나를 사전 지정한다. 완전한 수면/각성 시계열이 부족하면 취침/기상 변동성을 사용한다. SRI는 낮잠과 결측 처리까지 정의한 뒤 사용한다.
- 주간 기능은 정해진 시각의 졸림 평가, 필요 시 같은 기기/조건의 주의력 과제를 보조 결과로 한다.
- 표본수는 주 결과의 의미 있는 차이, 참가자 내 상관, 탈락률을 정한 뒤 산출한다. 현재 모델 오차만으로 임의의 표본수를 정하지 않는다.
- 분석은 배정군 기준을 우선하고, 추천을 잘 따른 사람만 고르는 분석은 탐색적으로 구분한다. 추천 자체가 행동을 바꾸므로 관찰모드 예측과 추천 노출 이후 예측을 따로 해석한다.
- 연구윤리 검토와 동의서에서 수집 항목, 저장·백업 위치, 보존기간, 철회·삭제 절차를 정한다. 실제 모집·무작위 배정은 이 문서 생성으로 시행되지 않는다.

S는 각성 중 상승하고 수면 중 감소하는 계산 상태다. S 감소만을 효능 종점으로 쓰면 자기 모델을 자기 모델로 평가하게 된다. 독립 관측 결과가 필요하다. [Borbély 등, 2016](https://doi.org/10.1111/jsr.12371), [SRI 원 연구](https://doi.org/10.1038/s41598-017-03171-4), [CONSORT-EHEALTH](https://www.jmir.org/2011/4/e126)

## 생리 상수를 연구하려면

현재 τ각성=18.2h, τ수면=4.2h, 진폭=0.15는 고정 가정이다. 수면 습관의 중간시각은 DLMO가 아니다. 우선 모의 자료로 파라미터 회수 가능성, 서로 다른 파라미터 조합의 동일 예측, 민감도를 검사한다. 독립 측정 없는 상황에서 모든 파라미터를 동시에 자유롭게 학습시키지 않는다.

필요하면 부분 표본에 EEG/PSG 기반 서파활동, 표준화된 광노출 기록, 일주기 위상 측정을 추가하는 별도 프로토콜을 검토한다. Rusterholz 연구는 8명의 젊은 남성, 장시간 각성, EEG 기반 실험이라는 맥락이 있으며 일지만의 상수 추정을 검증하지 않았다. [Rusterholz 등, 2010](https://pubmed.ncbi.nlm.nih.gov/20394318/)

PCR은 어떤 분자 표지·채취 시각·수면 결과 간 가설을 검증할 것인지 먼저 정해야 한다. 현재 추천 모델에 임의의 PCR 계수를 추가하지 않는다.

| 후보 | 도움되는 부분 | 한계 및 도입 조건 |
|---|---|---|
| [GLOBEM 데이터](https://physionet.org/content/globem/1.1/) | 참가자별 약 10주 추적, 시계열 공백과 개인화의 외부 평가 후보 | 인증 접근 필요. 공개본은 특징 수준; Fitbit 파생 수면이며 PSG 정답 아님. 다음날 목표를 적법하게 재구성할 수 있는지 확인 |
| [GLOBEM 공식 코드](https://github.com/UW-EXP/GLOBEM) | 참가자/코호트 일반화 평가 구조 참고 | 현 주 과제는 우울 증상 예측. Apache-2.0 코드라고 데이터 권한까지 생기는 것은 아님. 그대로 실행해 SleepWell 성능으로 보고하지 않음 |
| [DREAMT](https://physionet.org/content/dreamt/2.2.0/) | 다중 웨어러블 센서와 PSG 기반 수면단계의 측정 검증 후보 | 장기 추천 효과 자료와 다름. 자료 접근·버전·동시 측정 범위를 확인한 뒤 센서 검증용으로 검토 |

GLOBEM 수면 변수는 수면/침상 시간, 첫·마지막 시각 등 특징으로 제공된다. 다음날 목표를 같은 날 전체 특징과 함께 쓰면 누수가 생기므로 날짜/집계창을 한 칸 이동하는 것만으로 충분한지도 확인해야 한다. [공식 수면 변수 설명](https://the-globem.github.io/datasets/datatypes/sensors/sleep)

## 해석과 차별성

기록 기반 개인화 추천 자체는 선행 SleepWake 연구와 겹친다. 이번 연구의 기여는 시간 누수를 통제한 개인화의 조건별 성능, 불확실성을 숨기지 않는 추천, 그리고 추후 대조시험으로 입증할 행동·기능 변화로 정의한다. [Song 등, 2025](https://doi.org/10.1093/sleep/zsaf160)

성인 초기 목표 7–9시간 범위는 일반 지침을 참고한 앱 운영 범위이며 개인 최적량의 추정구간이 아니다. 9시간을 모든 사람의 생리학적 상한으로 해석하지 않는다. [AASM/SRS 합의문](https://www.aasm.org/resources/pdf/adultsleepdurationconsensus.pdf)
