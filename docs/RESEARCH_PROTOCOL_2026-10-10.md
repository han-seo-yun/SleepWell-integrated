# 연구용 데이터·비교 실험 사전 설계 (2026-10-10)

이 문서는 이번 실행의 Test 점수를 보기 전에 고정한 설계다. 기존 개인 모델의 Test 기간은 이미 열람되었으므로 새 외부 검증이 아니라 재분석이다. 원본과 기존 전처리 파일은 수정하지 않는다. 행 단위 자료·분할 ID·예측·모델은 저장소 밖 `연구용데이터/`에만 둔다.

## 과제와 출처

| 실험 | 입력 | 정답 | 분할 / 해석 |
|---|---|---|---|
| MESA | 현재 안정된 ACT 파일의 activity/light | 1-wake | 사람 hash 70/15/15, 장치 파생 약한 라벨 재현 |
| Walch | 손목 활동·심박, 기존 전처리와 원본 대조 | 독립 PSG sleep/wake | 사람 70/15/15, 소규모 독립 정답 평가 |
| 개인 Samsung | 전처리 완료 수면 이력·결정시각 이전 심박/걸음 | 다음 주수면 시작/끝 | 날짜 순 70/15/15, 한 사람의 미래 행동 재분석 |
| 보조 NHANES 2017–18 | 같은 조사 주기 연령·성별·활동 설문 | 자기보고 평일 수면시간 | 개인 hash 70/15/15, 별도 집단 관찰 회귀 |

CMI/MMASH/Sleep-EDF는 전처리의 라벨·센서·시간 정렬을 점검하여 별도 적합성 기록을 남긴다. 정답 중심 창, 미래 보간, label-only 파일은 검증 없이 일반 예측 성능으로 사용하지 않는다. NHANES 조사 주기 간 개인 연결, MESA 사람과 Samsung 사람 연결, 미국 참고치를 한국 학생 정답으로 대치하지 않는다.

## 평가 규칙

1. epoch는 우선 **시간 집계 간격 30/60/120/300초**다. 신경망 학습 반복과 다르다. 사용 모델의 boosting 반복별 Train/Validation 곡선도 가능하면 저장한다.
2. 분류: dummy, 활동-only logistic, 센서 조합 logistic, histogram gradient boosting. 분할은 집계 전에 고정한다. 현재/미래 wake·stage·interval과 정답으로 만든 S 상태를 입력에서 배제한다.
3. 긴 epoch가 정답을 평탄화해 유리해지는 것을 막기 위해, 각 설정의 예측을 공통 원본 30초 격자에 투영하여 비교한다. 모든 설정에서 유효한 동일 시간 구간 사용. 집계 종료 이후에야 예측할 수 있으므로 지연을 명시한다. 실제 미래 예측과 혼동하지 않는다.
4. 분류 주지표는 **참가자별 balanced accuracy의 평균**. accuracy, macro-F1, 각성 특이도, 수면 민감도, confusion, 커버리지 병기. Validation으로 선택하고 고정된 Test 후보 비교는 기술적·탐색적으로만 보고한다. Test 최고값으로 재선택하지 않는다.
5. 개인 미래 예측: 20:00 KST 기준, 시작이 이후 16시간 내인 QC 주수면. HR 1분·steps 10분은 구간 끝이 cutoff 이하인 것만 사용. 이력은 cutoff 전에 완료되고 지난 28일 내인 최근 7개까지. 생체 상태가 아닌 과거 행동 특징이다. 원본에 동기화 시각이 없으므로 실제 당시 입수 가능성은 미검증이다.
6. 회귀: 학습 중앙값, Ridge alpha 1/10/100, HGB 반복 20/60/120 비교. 개인은 일지-only / sensor-only / combined, NHANES는 연령·성별 / 활동 추가 비교. 대치·표준화는 Train에서만 fit. 선택은 Validation MAE. Test MAE·RMSE·중앙/P90 절대오차와 기준선 대비 paired bootstrap을 보고한다.
7. NHANES 기존 전체표 평균은 Test를 포함하므로 그대로 학습하지 않는다. 개인 단위 원표에서 다시 분할하고 연령대 중앙값 prior를 Train만으로 계산한다. 표본 가중치 성능을 별도로 보고하되 복합표본 설계 추론/인과효과로 주장하지 않는다.
8. 자원 제한: 파일별 처리, native threads 2 이하/실험. MESA는 모든 적합 자료를 저장하되 Train은 사전 지정 사람별 균등 상한으로 샘플링한다. 샘플링 수와 평가 전체 커버리지 기록. 작은 실험은 모두 학습.
9. 이번 실험으로 수면 개선·질환 진단·한국 사용자 전이·추천 효과를 입증하지 않는다. 연구 모델을 자동으로 웹 권장 정책에 승격하지 않는다.

## 완료 증거

코드·회귀 테스트, 데이터 snapshot/hash와 QC, 분할 manifest, 모델용 데이터, 설정별 지표, 검증 선택 기록, 실제 Test 예측, 재실행 명령과 환경 버전, 미사용 사유를 함께 남긴다. 추가 데이터는 새로운 snapshot으로 처리하되 기존 사람의 hash 분할을 바꾸지 않는다.
