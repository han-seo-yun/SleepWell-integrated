# 소빈·채윤 공동 업무 인계 — 웹앱 개발·소프트웨어화·시연영상

작성일: 2026-10-10 · 공동 담당: 소빈·채윤 · 총괄/모델 최종 통합: 서윤 · 기간: 착수 후 2주

이 문서는 전달용 업무 명세다. 팀원에게 메시지를 발송하거나 GitHub 담당자를 지정한 상태는 아니다. 전체 계획은 `TEAM_2WEEK_EXECUTION_PLAN_2026-10-10.md`다. 기존 링크 보존을 위해 파일명은 유지하지만 최신 담당자는 소빈·채윤 두 사람이다.

## 맡길 일 한 문장

**현재 SleepWell 웹앱을 다른 사람이 설명서를 보고 실행할 수 있는 연구용 소프트웨어로 정리하고, 정상 흐름과 데이터 부족 상황을 보여주는 시연영상을 제작한다.**

## 역할 경계

- 소빈: 웹 화면·입력/결과/오류 안내·사용 흐름 테스트·사용 설명서·시연영상.
- 채윤: 서버/API 운영부·기록 저장/백업·설정·실행기·패키지·서버/회귀 테스트·설치/문제 해결 안내.
- 서윤: 예측 모델 선정, 물리/권장 정책 정의, 모델 어댑터·최종 앱 통합과 승인.
- 혜지: 설문/연구 데이터 QC·성능 실험·모델/지표 제공 + 기존 채윤 담당이던 PCR 확장 문헌·후속 데이터 조사. 질병 기능을 이번 웹 필수 기능으로 추가하지 않는다.

소빈·채윤은 모델 내부를 다시 학습하거나 MESA 원본을 보유할 필요가 없다. 먼저 합성 입력/출력으로 웹을 개발하고 서윤이 승인한 인터페이스로 교체한다. 위 두 사람의 세부 분업은 제안이며, 같은 파일 수정 전 담당 구간을 합의하고 서로의 작업을 덮어쓰지 않는다.

현재는 `127.0.0.1:8765`의 로컬 1인 프로필 앱이다. 다중 사용자 인증·인터넷 회원가입 서비스가 아니며, 개인 SQLite 기록은 서버 재시작 뒤에도 남는다. 연구 모델 학습 완료가 곧 웹 권장 정책 적용 완료를 뜻하지 않는다.

## 필수 작업 — 소프트웨어화

1. **실행:** Windows 우선의 재현 가능한 실행 절차. 기존 실행기 재사용. Python/필요 파일/포트 충돌 오류를 사람이 이해할 수 있게 안내한다. Mac은 실제 검증한 범위만 표시한다.
2. **설정:** 외장 드라이브·개인 PC 절대경로에 의존하지 않게 데이터/모델/저장 경로를 설정화한다. 실제 개인정보 없는 설정 예제를 제공한다.
3. **독립 실행:** 연구 원본 또는 선택 의존성이 없어도 수동 입력·합성 데모로 실행된다. 데이터 없음과 서버 장애를 구분한다.
4. **사용 흐름:** 프로필→목표 기상/수면 기회→권장 결과→다음 날 기록→기록 확인. 예측 시각·권장 시각·측정 수면시간을 별도 표시한다.
5. **상태:** 초기 모드/개인화 조건 미충족/모델 없음/비호환/예측 불가/연구 전용 상태와 모델·정책 버전을 표시한다. 미검증 confidence 숫자를 만들지 않는다.
6. **오류 처리:** 빈 입력, 잘못된 시간/날짜, 자정 넘김, 중복 기록, 센서 미입력, 모델 버전 불일치의 동작을 정한다. 예측이 불가능할 때 그럴듯한 숫자로 채우지 않는다.
7. **저장·백업:** 기록 저장·재시작 보존·백업 내보내기를 테스트한다. 복원 UI는 검증/확인/충돌 정책까지 가능한 경우에만 구현하고, 미지원이면 설명서에 명시한다. 기존 DB를 자동 초기화하지 않는다.
8. **안전:** 기본 localhost 유지. 실제 DB·응답·토큰·개인 타임라인은 Git/ZIP/영상 제외. 다른 사람 프로필을 같은 기록에 덮어쓰지 않도록 안내한다.
9. **검증:** 기존 자동 테스트와 추가 회귀 테스트 결과, 실제 설치/실행한 환경, 남은 버그를 함께 제출한다.
10. **인계:** 소스/버전 태그 또는 commit 식별자, 설정 예제, 실행 명령, 사용/백업/문제 해결 안내, 합성 데모, 영상 파일을 같은 버전으로 묶는다. 외부 push/배포는 별도 승인 범위에서 수행한다.

EXE·Electron·PWA·클라우드·모바일 앱을 새로 만드는 것은 필수가 아니다. 새로운 프레임워크/의존성은 필요성을 서윤과 합의하기 전 추가하지 않는다.

## 서윤에게 받을 것

- 고정 입력·출력 명세: 이름, 단위, 시간대, 시점, 결측, 모델/정책 버전, fallback 이유.
- 정상/정보 부족/모델 오류를 포함하는 개인정보 없는 합성 예제.
- 웹 입력에 맞는 승인 모델 또는 명시적인 모델 미탑재 상태. MESA ACT 분류 모델을 취침 권장 모델로 사용하지 않는다.
- 허용 오차가 정해진 연구 코드↔웹 출력 검증 예제와 연구용 표시 문구.

## 시연영상 구성 — 3~5분

1. 목적과 한계: 연구용 일정 제안, 질병 진단 아님.
2. 실행→합성 프로필 입력→목표 기상/수면 기회 입력.
3. 권장 결과·이유와 행동 예측의 차이를 보여준다.
4. 다음 날 기록→저장→재시작 후 보존을 보여준다.
5. 데이터 부족/모델 없음 상황의 안내를 보여준다.
6. 현재 성과·검증 범위·후속 과제를 요약한다.

합성 데이터는 화면에서 합성이라고 표시한다. 개인화 전환을 보여주려면 합성 날짜/기록임을 명시하며 실제 14일 추적이 완료된 것처럼 연출하지 않는다. 센서 분류 BA를 권장시간 정확도로 소개하지 않는다.
