# SleepWell: 기준선·개인 내 변화·측정 타당성 검증

작성일: 2026-10-25. 탐색적 후향 검증. 연구자 소프트웨어 0.4.2 반영.

## 적용한 연구 방법

passive-sensing-target-validity 저장소의 핵심인 강한 과거 기록 기준선, 개인 간 차이와 개인 내 변화의 구분, 측정 대상의 타당성, 개인화에 필요한 관측기간 점검을 SleepWell의 기존 자료에 맞게 독립 구현했다. 해당 저장소의 결과·모델 계수·GLOBEM 자료를 SleepWell 성능으로 전용하지 않았다. 참고 커밋은 627b1006a95b698a0f9f74ff19d499a8a0ef5a60이다. 저장소 보고서는 연구 프로젝트 보고서이며 동료심사 논문으로 취급하지 않는다.

## 자료와 평가 설계

CMI 44명 673밤, MESA 315명 2,175밤의 기존 Test 전체를 유지했다. 비교 모델은 continuous_constants_run_20261025_v2의 TRAIN 선택 정책으로 생성된 동결 예측이다. CMI는 daily_pattern_h14_l14, MESA는 daily_mean_h28_l28이다. 현재 서비스에 탑재된 robust-v2 모델과 구분한다.

추가 기준선은 TRAIN 집단 평균, 직전 관측(최근 28일 이내), 최근 7일 평균, 최근 14일 평균, 최근 28일 최근성 가중평균(반감기 14일), 같은 요일 평균이다. 모든 기간은 행 개수가 아니라 달력상의 경과시간으로 계산한다. 같은 요일 관측이 2회 미만이면 최근 14일 평균을 사용한다. 과거 자료가 없으면 TRAIN 집단 평균으로 돌아간다. 모델과 동일하게 20시 기준의 제한된 분 단위 좌표를 사용하며 원형평균은 아니다.

각 예측 시점보다 이전에 수면이 끝나고 관측 가능했던 기록만 사용한다. 당일 목표값은 예측 후 다음 시점의 이력에 추가한다. 원자료·시험 행의 동일성, 참여자 간 분할 독립성, TRAIN 집단 평균의 재계산 일치, 입력 파일 해시 불변을 확인했다. 이 감사는 새로운 기준선의 시간 경계를 검증한다. 동결 모델의 원 학습 전 과정을 이번에 재학습하거나 새롭게 독립 검증한 것은 아니다. 후향 자료의 관측 가능시각은 기상시각으로 가정되어 실제 제출 지연을 재현하지 못한다.

주 비교 기준선은 최근 14일 평균으로 미리 고정했다. 오차가 큰 밤을 결과에 따라 제외하지 않았다. 기존 Test를 재사용하므로 새 외부 검증이나 확증시험으로 주장할 수 없다. 여러 기준선 중 시험 성능이 가장 좋은 것을 서비스로 자동 채택하지 않는다.

## 성능 결과

지표는 각 사람의 입면·기상 절대오차 평균을 구한 뒤 사람마다 동일한 가중치로 평균한 MAE(분)이다. 총수면시간, 수면의 질, 수면압력 또는 추천의 효과 지표가 아니다.

| 모델/기준선 | CMI MAE(분) | MESA MAE(분) |
|---|---:|---:|
| TRAIN 집단 평균 | 69.69 | 87.85 |
| 직전 관측 | 60.35 | 81.26 |
| 최근 7일 평균 | 53.84 | 73.65 |
| 최근 14일 평균 | 54.54 | 73.65 |
| 최근성 가중평균 | 54.27 | 73.53 |
| 같은 요일 평균 | 54.47 | 73.65 |
| 물리 단독 | 60.71 | 86.66 |
| 데이터 단독 | 47.31 | 67.93 |
| 융합 | 47.53 | 68.09 |

융합 모델은 최근 14일 평균보다 CMI 7.02분(12.86%), MESA 5.55분(7.54%) 오차가 작았다. 참여자를 단위로 10,000회 짝지은 부트스트랩을 시행한 개선량의 95% 구간은 각각 [3.80, 10.57]분, [4.16, 6.97]분이다. 개인 평균오차가 감소한 비율은 각각 77.3%, 71.4%이다. 이 비율은 개인별 통계적 유의성이나 모든 미래 사용자의 개선 확률이 아니다. 구간은 다중비교 보정 전 기술적 구간이다.

기준선 대비 skill = 1 − MAE(모델)/MAE(최근 14일 평균). 분모가 1분 미만이면 비율은 계산하지 않는다. 이 수치는 선택한 기준선 대비 예측 이득이며 개인의 생리학적 고유 상수가 아니다.

융합은 데이터 단독보다 CMI 0.21분, MESA 0.16분 오차가 컸다. 기존 매일상수 실험의 물리 특성 추가 효과 95% 구간은 CMI [-0.58, 0.18]분, MESA [-0.37, 0.04]분으로 0을 포함한다. 따라서 현재 물리 특성 추가의 예측 향상은 확인되지 않았다. 물리 단독은 최근 14일 평균에도 뒤졌다.

## 개인 내 변화와 개인화의 해석

사람별 시험기간 평균을 관측값과 예측값에서 각각 빼고, 일별 변동을 설명하는 정도를 진단했다. 이 평균 제거는 평가에만 사용하며 예측 입력이나 학습에는 사용하지 않는다. 3밤 이상이고 변동이 있는 사람만 포함한 centered R² 중앙값은 융합 CMI 입면 -0.200·기상 -0.060(41명), MESA 입면 -0.288·기상 -0.279(315명)이다. 이 값은 평균 편향을 제거한 진단용 지표이며 배포 가능한 ‘개인 평균’ 기준선의 성능이 아니다.

절대시각 예측은 최근 기록 평균보다 좋지만 개인 내 일별 변동 추적은 아직 약하다. held-out 개인별 시간 변동과 융합 MAE의 Spearman 상관은 CMI 0.782, MESA 0.933이다. 오차가 작은 사람은 원래 수면이 규칙적이었을 수 있다. 동일 시험자료를 이용한 기술적 연관이며 생리적 예측가능성·인과관계를 입증하지 않는다.

MESA에서는 예측 이전 기록이 최대 8개여서 14일·28일의 충분한 개인별 패턴 또는 반복 요일 학습 효과를 검증할 수 없다. 실제로 같은 요일 기준선은 최근 14일 평균으로 되돌아갔다. 첫 기록부터 점진적으로 개인화하는 기존 구조는 유지하되, ‘활성화 가능’과 ‘충분히 검증된 개인화’를 구분해야 한다. 기록 개수별 표에는 동일 참여자가 여러 구간에 반복 포함되고 구간별 표본 구성도 달라진다. 따라서 그 차이만으로 기록 축적이 성능을 향상시킨다고 해석할 수 없다.

## 휴대폰 자료 품질과 연구 화면

연구자 화면에 ‘기준선 대비 예측 이득’ 및 ‘측정자료 일치도’를 추가했다. 전자는 코호트별 기준선, 모델 MAE, 상대 개선량, 신뢰구간, 개인별 개선 비율 및 이력 구간별 결과를 표시한다. 후자는 실제 가져온 휴대폰 백업에서 출처별 기록 수, 관측된 날짜 범위, 날짜 밀도, 중복·유효하지 않은 기록 수, 일지–웨어러블 시각 차이를 계산한다. 실제 자료가 없으면 수치를 만들어 채우지 않는다.

일지와 같은 출처의 웨어러블 기록이 각각 1건이고, 한국시간 기상 날짜가 같으며 수면구간이 겹칠 때만 짝지어 비교한다. 중복 또는 겹치지 않는 기록은 일치도 계산에서 제외하고 별도로 센다. 중앙 절대 차이, 평균 부호 차이, 30분·60분 초과 비율을 제공한다. 20쌍 이상에서만 부호 차이의 경험적 2.5–97.5 백분위 구간을 표시한다. 이는 평균차의 신뢰구간이나 임상적 일치한계가 아니다.

‘기록된 취침시각’은 수동 입력에서는 누운 시각, 기기에서는 알고리즘이 추정한 시작시각일 수 있다. 이 차이를 생리적 입면 오차로 단정하지 않는다. PSG 정답 자료와의 검증도 아니다. 수정시각 지연은 최초 제출 지연과 구분한다. 날짜 밀도는 등록기간 전체 순응도나 센서 착용률이 아니다. 분석은 원본 기록을 수정·제외하거나 모델 학습용 라벨로 덮어쓰지 않는다.

Android 앱의 기존 백업 계약으로 가져온 자료를 연구자용 소프트웨어에서 분석한다. 이번 변경에 새 APK 배포나 추천 모델 교체는 포함하지 않았다. 새 집계 산출물에는 개인 식별자나 밤별 원자료가 없으며, 배포판은 명시적 허용 파일만 포함한다.

## 다음 연구의 우선순위

1. 예측: 새로운 참여자·미래 기간에 예측시각과 당시 이용 가능 정보를 미리 고정하고 실제 결과를 나중에 연결한다. 미관측 신규 사용자와 기존 사용자의 미래 예측을 분리한다. 입력 결측·웨어러블 미착용을 구분하고 기기·라벨별 민감도 분석을 계획한다.
2. 개인화: 4–8주 이상의 반복 관측을 확보해 요일 반복, 일정 변화, 공백 후 회복을 관찰한다. 기간은 설계 제안이며 충분한 검정력을 보장하는 기준은 아니다. 개인 기록은 최근성 가중과 집단 평균으로의 수축을 유지하고, 후보 반감기·규제강도는 훈련자료 내부의 참여자·시간 분리에서만 선택한다.
3. 물리 특성: 수면/각성 이력뿐 아니라 낮잠, 카페인의 시각·양, 빛 노출, 일정 제약을 예측시점 이전에 수집한다. 동일 학습기·동일 자료·동일 튜닝 예산으로 생리적 특성과 단순 과거기록 요약의 추가가치를 비교한다. 행동 기록만으로 수면 항상성 시간상수를 측정했다고 주장하지 않는다.
4. 추천: 관측된 실제 수면을 잘 맞히는 것과 최적의 권장 일정을 찾는 것은 별개다. 일정 제약·사용자 선호·불확실성을 명시하고, 수면압력 최소화를 단일 목적함수로 삼지 않는다. 목적함수의 가중치는 이번 Test 결과로 선택하지 않는다.
5. 효과: 추천 조건과 비교 조건을 무작위화한 시험 또는 적절한 반복 교차 설계로 규칙성, 다음날 기능, 주관적 수면 질, 추천 준수율을 평가한다. 교차 설계라면 잔류효과를 고려한다. 실제 모집 설계와 최소 의미 효과를 정한 뒤 표본수를 계산한다.
