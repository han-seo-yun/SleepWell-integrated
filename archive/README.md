# Historical archive

This directory keeps source snapshots and planning documents that are useful
for project history but are not part of the current application entry points.

- `legacy-root-kotlin/`: original standalone Kotlin snapshots. The current
  Android application uses `android-app/`.
- `historical-documents/`: meeting notes, earlier agreements, and superseded
  integration/epoch notes. Current operational and research documents are in
  `docs/`.

The active verification sources under `src-epoch-*` remain outside this archive
because `tools/verify/` references them directly.
